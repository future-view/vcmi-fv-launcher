# ADR 0004：百科缓存索引只合并不删除

- 状态：已采纳
- 相关：[modcache](../features/modcache.zh-CN.md) §10

## 背景

切换领域时，各领域缓存的模组集合不同。若构建时按"当前可见集合"清理索引，切换回来就要重建，代价高。

## 决策

`mods/index.json` **只合并不删除**；已卸载 / 属于其它领域的条目靠**读侧** `visibleModKeySet()`（实时 `scan_mods` ∪ core 伪模组）过滤。不做自动 GC。

## 理由

领域切换的可见性优先于索引体积；缓存重建的成本远高于留着条目。

## 后果

- 索引会缓慢膨胀（"孤儿条目"），这是**刻意取舍**，不要加自动 GC；
- 若要改善体验，走**软标记 + UI 过滤**的方向，不要在构建期删除。
