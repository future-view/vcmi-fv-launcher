# 外壳与导航

> 状态：已实现 ｜ 最后核对：2026-09-30 ｜ 代码：`src/shell/`、`src/App.tsx`、`src/shared/WindowControls.tsx`

## 1. 顶栏（`shell/TopBar.tsx`）

| 元素 | 行为 |
|---|---|
| 品牌 + 拖拽区 | 无边框窗口的拖拽把手 |
| 页签：领域 / 模组 / 百科 | 领域进入顶级页面（另一套模式） |
| 语言按钮 | 切换界面语言，见 [i18n](./i18n.zh-CN.md) |
| 齿轮 | **是内容区切换（toggle），不是页签**：切到设置视图 |
| 更新红点 | 有可用更新时在齿轮上显示角标 |
| 窗口控件 | 最小化 / 最大化 / 关闭 |

## 2. 底栏（`shell/BottomBar.tsx`）

- 左侧：活动领域徽标、`导入游戏文件`、`游戏数据`、`帮助`；
- 右侧：`官方启动器`、`编辑器`、`启动游戏`；
- 另承载 Toast 提示。

## 3. 游戏数据抽屉（`GameDataDrawer`）

展示三组信息：

1. **环境**：引擎版本（权威来源是 `VCMI_client.exe -v`，**不要**用 exe 的 PE 版本资源或 `mod.json` 的 `1.5`）、核心模组、操作系统；
2. **目录**：游戏目录与各用户目录（可点击打开）；
3. **健康检查**：只读体检结果，分四档 —— 正常 / 警告 / 致命 / 不可用。

## 4. 帮助抽屉（`HelpDrawer`）

三层结构：头部 → 搜索框 + `##` 目录 → 正文。搜索按块过滤并**保留章节上下文**。内容来自内置 Markdown（5 语），解析见 [i18n](./i18n.zh-CN.md) §4。

## 5. 导入弹层（`ImportFilesDialog`）

见 [game-import](./game-import.zh-CN.md) §4（四态：空态 → 有文件态 → 执行中 → 结果态）。

## 6. 错误边界

`ErrorBoundary` 在 `main.tsx` 中包住 `App`，捕获渲染异常并显示堆栈、写控制台——保证白屏时有可读信息。

## 7. 窗口

- 最小化 / 最大化 / 关闭走 Tauri 命令（`shared/WindowControls.tsx`）；
- 最大化状态通过窗口 API 与 resize 事件双向校准；
- 最小尺寸基准 960×640。

## 8. 渲染优先级（`App.tsx`）

```
启动遮罩 → 首启向导 → 强制更新覆盖层 → 领域模式 → 主界面
```

首启向导优先于强制更新（先让用户把目录配好）；配置就绪后强制更新阻断一切。
