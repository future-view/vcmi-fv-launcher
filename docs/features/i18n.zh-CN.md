# 多语言

> 状态：已实现 ｜ 最后核对：2026-09-30 ｜ 代码：`src/i18n/`、`src/lib/vcmiLangs.ts`、`src/lib/vcmiLanguage.ts`、`src/lib/modcache/index.ts`、`src/lib/helpDoc.ts`、`src-tauri/src/vcmi/i18n.rs`

## 1. 三套语言体系

本项目有三条互不相同的语言链路，容易混淆：

| 体系 | 用途 | 语言集 |
|---|---|---|
| **界面语言** | 启动器 UI 文案 | chinese / english / russian / polish / german（5 语） |
| **VCMI 内容语言** | 模组文本、百科条目取词 | VCMI 语言 identifier（chinese / tchinese / english / …） |
| **帮助文档语言** | 内置离线帮助 | zh-CN / en / ru / pl / de（5 语文件） |

## 2. 界面语言

- 词典在 `src/i18n/`：`zh-CN.ts` / `en.ts` / `ru.ts` / `pl.ts` / `de.ts`，另有 `settingsText.*` 提供设置项文案，**强类型**约束。
- `tchinese` 界面回退到 `chinese`（`i18n/index.ts` 的 `UI_FALLBACK`）。
- 切换命令 `set_ui_lang`。
- **按语言的能力开关**：`src/i18n/langs.ts` 的 `UI_LANG_FEATURES`（`Record<UiLang, …>`）。
  凡"某功能只面向部分语言"的判定（如首启向导是否建议开启 GitHub 镜像）一律查这张表，
  **禁止**在业务代码里写 `lang === "chinese"` 之类的字面量；加语言时编译器会要求补一行。
  当前字段：`githubMirrorHint`。

## 3. VCMI 内容语言

- 标识映射在 `lib/vcmiLangs.ts`（VCMI identifier ↔ 本地化名称）。
- 百科取词：`contentLangKey` 把 UI 语言转成 VCMI 标识；`pickName` 按「当前语言 → english」严格回退。
- **当前实现**：除 chinese / tchinese 外一律映射到 english（其它 VCMI 语言的词条尚未接入取词链）。
- 模组文本由后端 `vcmi/i18n.rs` 解析 mod.json 里的多语言块（`NON_I18N_KEYS` 之外的对象块），并支持跨模组祖先链。
- **必须同步** `general.language`：否则 VCMI 会把 Translation 类模组判为 BROKEN 并回写移除（命令 `set_vcmi_language`，幂等）。

## 4. 帮助文档

- 文件：`src/assets/help/help.{zh-CN,en,ru,pl,de}.md`。
- 解析：`lib/helpDoc.ts` —— **无 React** 的受控 Markdown 子集解析器，输出 `Block[]`；`HelpDrawer` 负责渲染三层结构（头部 / 搜索 + `##` 目录 / 正文）。
- 搜索按块过滤并保留章节上下文。

## 5. 领域多语言

- `realm.json` 的名称 / 描述 / 标签按语言存；编辑器每语言 ≤6 个标签、单标签 ≤16 字。
- 登场演出取词与 BGM 由 `lib/realm/intro.ts` 处理多语言回退。

## 6. 错误文案

后端只抛结构化错误 `be_err(code, arg)` → `{"code","arg"}`；前端 `lib/backendError.ts` 按 `code` 查当前语言词典，**缺译回退中文**，用 `{arg}` 插值。禁止 `String(e)` / `e.message` 或按译文匹配。

## 7. 边界与容错

- 任何一层缺译都回退，绝不显示空白或 key 名。
- 新增语言需同时补：i18n 词典、settingsText、help 文件、VCMI 标识映射。

## 8. 开放问题

- 界面支持 5 语，但百科内容取词只实际区分中 / 英，其余语言待接入。
