# VCMI-FV 启动器帮助

> 本文档随启动器版本更新，无需联网；界面语言切换后自动显示对应语言版本。

## 快速上手

### 首次启动

- 首次打开会进入初始化向导：选择**游戏目录**（须包含 `VCMI_client.exe`）与**用户数据目录**（通常为 `文档\My Games\vcmi`），保存后进入主界面。
- 目录识别优先读游戏目录的 `config/dirs.json`，读不到时回退 VCMI 默认规则。

### 四步开始游戏

1. 顶部「领域」→ 创建或进入一个领域（可选；不进入领域则使用全局配置）。
2. 「模组」页左栏挑城镇/扩展，右栏确认（依赖会自动勾选）。
3. 顶部预设栏点「保存」，写入 `modSettings.json`。
4. 底栏「启动游戏」启动 VCMI。

### 底栏速览

- 左侧：导入游戏文件 / 游戏数据 / 帮助 / 官方启动器。
- 右侧：地图编辑器 / 启动游戏。

## 模组与预设

### 预设是什么

- 预设 = 一组模组开关（`mods` 数组 + 子模组 `settings[父][子]`），保存在 VCMI 的 `modSettings.json`。
- 顶部预设栏支持：切换、保存（检测到变动才激活）、新建（可继承自其他预设）、重命名、导入导出官方单预设格式、删除、生成 Markdown 启用报告。

### 依赖与冲突

- 勾选模组时自动勾选其 `depends` 硬依赖；`conflicts` 冲突项在右栏标红。
- 缺失模组、依赖未满足或存在冲突时，启动前会弹窗列出原因。

### 子模组

- 父 mod 展开后可单独勾选子项，写入 `settings[父][子]`；子项 ID 保留空格与点号（如 `minotaur warlock.new mino warlock`）。

### 可启动基线

- 保存时会自动并入最小化基线（默认增强版 `vcmi` / `h3e-main-menu` / `core`），保证游戏可启动。

## 领域系统

### 隔离原理

- 领域 = 一套独立的 VCMI 环境：启动器改写游戏目录的 `config/dirs.json`（只动 VCMI 识别的 5 个 key：`userDataPath` / `userConfigPath` / `userCachePath` / `userLogsPath` / `userSavePath`），把用户目录指向领域自己的目录。
- 停用领域时**按原文备份还原**（不是写"官方默认路径"）。
- 领域数据默认位于 `%LOCALAPPDATA%\VCMI-FV-Launcher\realms\<id>\`，不放进游戏目录。

### 模组的三种引用

- **默认引用**：直接使用用户目录与游戏目录里的模组，不复制。
- **整合**：把模组复制进领域目录，随领域一起导出/迁移。
- **借用**：以目录联接（junction）借用外部模组；解除引用只删联接，不动源文件。

### 地图屏蔽阀门

- 开启「屏蔽游戏自带地图」时，启动器会把游戏目录的 `Maps` 改为 `Maps.vcmi-fv-native` 并建立联接（默认态完全透明）；关闭屏蔽只移除联接。随时可还原。

### 进入与退出

- 进入领域会执行激活（改写 dirs.json、播种领域预设、落地借用模组）；退出领域会停用并还原。
- 领域界面没有底栏：启动游戏、地图编辑器入口在领域主界面内。

## 设置面板

### 打开方式

- 右上角齿轮按钮打开设置；**再点一次**（或点任一页签）离开。设置不是页签。

### 显示级别

- 三档：**常用 / 进阶 / 全部**，控制进阶与全部级设置项的显隐，默认「常用」。
- 搜索框会跨级别命中设置项，是找隐藏项的另一条捷径。

### 作用域状态

- 顶部区右侧的「全局共享 / 领域独立」是一个**只读状态**：鼠标悬停或点击会展开面板，说明这些设置写入哪个配置目录，并支持一键复制路径。
- 启动器设置页恒为「全局共享」；领域设置页按该领域的配置策略显示「全局共享」或「领域独立」。

### 更多菜单

- **运行信息**：按当前配置目录读取最近地图/存档、游戏数据语言、已启用模组数、VCMI 版本等。
- **检查更新**：仅启动器设置页显示。
- **打开配置目录**：在资源管理器中打开当前配置目录。
- **重置为默认**（红字）：把该目录下所有本启动器可管理的 VCMI 设置项恢复为游戏内置默认值，请谨慎操作。

### 写入语义

- 只有偏离默认的值才会写进 `settings.json`；把某项改回默认值等于删除该键，交还给 VCMI 内置默认（游戏升级后自动受益）。

## 更新

### 如何得知有新版本

- ⚙ 按钮红点：任何页面可见。
- 「更多」按钮红点 + 菜单内版本徽标：设置页内可见。
- 自动弹窗：同一版本 **7 天内最多提醒一次**；发现**新版本**会立即提醒一次。
- 「跳过此版本」= 永久忽略该版本（红点与徽标消失）；主动点「检查更新」仍可查看结果。

### 强制更新

- 当清单声明最低可用版本且当前版本过低时，启动器会全屏阻断，只能更新或退出。

### 下载与安装

- 弹窗内下载并校验 sha256；纯配置更新包可就地应用（无需关闭启动器），含 exe 的包会生成替换脚本，关闭启动器后自动替换并重启。

## 高清素材

### HD 素材来源

- 检测到官方 HD 版素材 mod（`hd-edition`）时：`@2x` / `@3x` 变体优先取真高清生成，城镇幕布与兵种背景的基准图改用 HD 尺寸合成图；其余类别基准图仍是原版。
- 可在设置 →「FV启动器」（切到「全部」级别）里切换来源（auto / 关闭）与档位（auto / x2）。

### AI 超分

- 开启「AI 高清增强」后，插画类（兵种 / 英雄 / 建筑）改用 AI 超分；像素画仍走 xBRZ 放大。
- AI 依赖「AI 运行库」组件，且必须在设置里**显式选择模型**才会生效（不选 = AI 不参与）。

### 生效条件

- 改动开关或档位后，需要**重建素材缓存**才会生效（首次会重跑素材阶段）。

## 网络

### GitHub 代理

- 无法直连 GitHub 时，在设置 →「FV启动器」→「GitHub 网络代理」填写 HTTP(S) 代理（如 `http://127.0.0.1:7890`）；留空 = 直连。
- 仅对 GitHub 地址生效：先直连，连接失败才改走代理；不支持 socks5（请填代理客户端的混合端口）。

### 镜像规则表

- 「GitHub 镜像规则」卡片可维护镜像表：直连失败后按顺序尝试镜像，全部失败再落到代理。

## 目录与数据

### dirs.json 机制

- VCMI 只识别 5 个 key（`userDataPath` / `userConfigPath` / `userCachePath` / `userLogsPath` / `userSavePath`），其余字段会被静默忽略。
- 路径经环境变量展开；相对路径按进程工作目录解析，因此必须写绝对路径。
- 游戏目录的 `Mods` 与用户目录的 `Mods` 会**同时**挂载，地图同理。

### 游戏数据抽屉

- 底栏「游戏数据」可查看：引擎版本、核心 mod 版本（与引擎版本不是一回事）、操作系统、各数据目录（可一键在资源管理器打开）、数据完整性体检（LOD 条目 / 核心 mod / 资源容器）。

### 导入游戏文件

- 底栏「导入游戏文件」，或直接把文件拖进窗口：支持 `zip` / `h3m` / `h3c` / `vmap` 等；zip 会自动识别为模组包并安装到用户模组目录。

## 常见问题

### 提示模组缺失怎么办？

- 预设里引用的模组在磁盘上不存在（换过目录或删过模组）。到「模组」页补齐，或从仓库安装；缺失的是语言模组时，提示条会给出「从仓库安装」按钮。

### VCMI 版本是怎么读出来的？

- exe 本身没有 PE 版本信息，启动器按 `VCMI_client.exe -v` → PE 版本 → 扫描的顺序探测；「游戏数据」里的核心 mod 版本（如 `1.5`）是内置 mod 的资产版本，不是引擎版本。

### 便携部署要注意什么？

- 把启动器 exe 放在任意目录（含游戏目录旁）即可，首次向导里指定目录；`launcher.json` 可预置语言、目录与开关，便于随包分发。

### 为什么更新提示有时不出现？

- 可选更新采用节流：每个版本首次发现提醒一次，之后 7 天内不再自动弹出（红点与徽标仍在）。想立刻查看可点「更多 → 检查更新」。
