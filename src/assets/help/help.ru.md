# Справка VCMI-FV Launcher

> Документ поставляется вместе с лаунчером и обновляется вместе с ним; при смене языка интерфейса показывается соответствующая версия.

## Быстрый старт

### Первый запуск

- При первом запуске открывается мастер настройки: выберите **каталог игры** (должен содержать `VCMI_client.exe`) и **каталог данных пользователя** (обычно `Документы\My Games\vcmi`), затем сохраните.
- Каталоги определяются по `config/dirs.json` в каталоге игры, иначе — по правилам VCMI по умолчанию.

### Четыре шага до игры

1. Вверху «Миры»: создайте или войдите в мир (необязательно; без мира используется глобальная конфигурация).
2. На вкладке «Моды» выберите города/дополнения слева и проверьте справа (зависимости включаются автоматически).
3. Нажмите «Сохранить» в панели предустановок, чтобы записать `modSettings.json`.
4. Нажмите «Запустить игру» в нижней панели.

### Нижняя панель

- Слева: импорт файлов / данные игры / справка / официальный лаунчер.
- Справа: редактор карт / запуск игры.

## Моды и предустановки

### Что такое предустановка

- Это набор переключателей модов (массив `mods` и подмоды `settings[родитель][потомок]`), сохраняемый в `modSettings.json` VCMI.
- Панель предустановок: переключение, сохранение (активируется при изменениях), создание (с наследованием), переименование, импорт/экспорт официального формата, удаление, отчёт Markdown.

### Зависимости и конфликты

- При выборе мода автоматически включаются его `depends`; конфликты (`conflicts`) подсвечиваются красным.
- Отсутствующие моды, невыполненные зависимости и конфликты блокируют запуск и перечисляются в диалоге.

### Подмоды

- Разверните родительский мод и отметьте подпункты — они записываются в `settings[родитель][потомок]`; пробелы и точки в ID сохраняются.

### Базовая линия

- При сохранении добавляется минимальная базовая линия (по умолчанию расширенная версия: `vcmi` / `h3e-main-menu` / `core`), чтобы игра запускалась.

## Миры

### Как работает изоляция

- Мир — независимая среда VCMI: лаунчер перезаписывает `config/dirs.json` (только 5 ключей: `userDataPath` / `userConfigPath` / `userCachePath` / `userLogsPath` / `userSavePath`), направляя пользовательские каталоги внутрь мира.
- При деактивации восстанавливается **исходная резервная копия** (а не «стандартные пути»).
- Данные мира по умолчанию: `%LOCALAPPDATA%\VCMI-FV-Launcher\realms\<id>\`.

### Три способа подключения модов

- **По умолчанию**: моды берутся из пользовательского и игрового каталогов без копирования.
- **Интеграция**: копирование модов в каталог мира (переносятся вместе с ним).
- **Заимствование**: junction-ссылка на внешние моды; отмена ссылки не удаляет исходники.

### Карты

- «Блокировать карты игры» переименовывает игровой каталог `Maps` в `Maps.vcmi-fv-native` и создаёт junction (по умолчанию прозрачно); отключение удаляет junction. Восстановление возможно в любой момент.

### Вход и выход

- Вход активирует мир (dirs.json, предустановка мира, заимствованные моды); выход деактивирует и восстанавливает.
- В интерфейсе мира нет нижней панели: запуск игры и редактор находятся на главном экране мира.

## Параметры

### Как открыть

- Кнопка-шестерёнка справа вверху переключает параметры; нажмите её ещё раз (или любую вкладку), чтобы выйти.

### Уровень отображения

- Три уровня: **Обычные / Расширенные / Все** (по умолчанию «Обычные»).
- Поиск находит пункты на всех уровнях.

### Область действия

- Метка «Общие глобальные / Только мир» справа вверху — **только состояние**: наведение или щелчок раскрывает панель с пояснением, в какой каталог конфигурации пишутся настройки, и кнопкой копирования пути.
- Страница параметров лаунчера всегда «Общие глобальные»; страница параметров мира зависит от его политики.

### Меню «Ещё»

- **Сведения о среде**: недавняя карта/сохранение, язык игровых данных, число включённых модов, версия VCMI — из текущего каталога конфигурации.
- **Проверить обновления**: только на странице параметров лаунчера.
- **Открыть каталог конфигурации**.
- **Сбросить к значениям по умолчанию** (красным): возвращает все управляемые лаунчером настройки VCMI в этом каталоге к встроенным значениям.

### Семантика записи

- В `settings.json` попадают только значения, отличающиеся от стандартных; возврат к стандартному значению удаляет ключ.

## Обновления

### Как узнать о новой версии

- Красная точка на шестерёнке — видна на любой странице.
- Точка на кнопке «Ещё» и метка версии в меню — внутри параметров.
- Автодиалог: одна версия напоминает **не чаще раза в 7 дней**; **новая** версия — сразу.
- «Пропустить эту версию» — навсегда игнорирует версию; «Проверить обновления» по-прежнему показывает результат.

### Принудительное обновление

- Если манифест задаёт минимальную поддерживаемую версию, лаунчер блокирует работу на весь экран.

### Загрузка и установка

- Диалог скачивает и проверяет sha256; пакеты только с конфигурацией применяются на месте (без перезапуска), пакеты с exe создают скрипт замены и перезапускают лаунчер.

## HD-материалы

### Источник

- При обнаружении официального HD-мода (`hd-edition`) варианты `@2x`/`@3x` генерируются из настоящего HD, а базовые изображения экранов городов и фонов существ берутся в HD.
- Параметры → «FV лаунчер» (уровень «Все»): источник (auto / выкл.) и разрядность (auto / x2).

### AI-апскейл

- При включении «AI HD enhance» иллюстрации (существа / герои / здания) обрабатываются AI; пиксель-арт — xBRZ.
- Требуется компонент «AI runtime» и **явно выбранная модель** (без модели AI не используется).

### Когда изменения вступают в силу

- После смены переключателя или разрядности необходимо **пересобрать кэш материалов**.

## Сеть

### Прокси GitHub

- Если GitHub недоступен, укажите HTTP(S)-прокси в параметрах → «FV лаунчер» → «Прокси GitHub» (например `http://127.0.0.1:7890`); пусто = напрямую.
- Работает только для адресов GitHub: сначала напрямую, прокси — при ошибке подключения. SOCKS5 не поддерживается.

### Правила зеркал

- Карточка «Правила зеркал GitHub»: после ошибки прямого подключения зеркала пробуются по порядку, затем прокси.

## Каталоги и данные

### Механизм dirs.json

- VCMI понимает только 5 ключей (`userDataPath` / `userConfigPath` / `userCachePath` / `userLogsPath` / `userSavePath`); остальные игнорируются.
- Пути раскрывают переменные среды; относительные разрешаются от рабочего каталога процесса — нужны абсолютные.
- Каталоги `Mods` игры и пользователя подключаются **одновременно**; то же для карт.

### Панель «Данные игры»

- Версия движка, версия основного мода (не версия движка), ОС, каталоги данных (открыть в проводнике), проверка целостности (записи LOD / основной мод / контейнеры ресурсов).

### Импорт файлов

- Кнопка «Импорт файлов» или перетаскивание в окно: `zip` / `h3m` / `h3c` / `vmap` и т. д.; zip распознаётся как пакет модов.

## Частые вопросы

### Предупреждение об отсутствующем моде

- Предустановка ссылается на мод, которого нет на диске. Добавьте его на вкладке «Моды» или установите из репозитория; для языковых модов в уведомлении есть кнопка «Установить из репозитория».

### Как определяется версия VCMI

- В exe нет PE-версии: лаунчер проверяет `VCMI_client.exe -v`, затем PE, затем сканирование. Версия основного мода (например `1.5`) — это версия встроенного мода, а не движка.

### Портативное развёртывание

- Разместите exe лаунчера в любом каталоге; укажите каталоги в мастере; `launcher.json` может предварительно задавать язык, каталоги и переключатели.

### Почему напоминания об обновлении иногда не появляются

- Необязательные обновления ограничены: одна версия напоминает один раз, затем 7 дней тишины (точка и метка остаются). Проверить вручную: «Ещё → Проверить обновления».
